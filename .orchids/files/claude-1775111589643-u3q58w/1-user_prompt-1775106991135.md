SIMPLIFIED DIGITAL ECOSYSTEM
One Core App + Two Execution Tools
Tools you already locked:
•	ClassDojo → daily learning interaction & parent-facing trust
•	Google Meet → live learning cells
Now we design ONE APP that becomes the central nervous system.
________________________________________
1. The Right Mental Model (Very Important)
Think of the system like this:
•	ClassDojo = classroom heartbeat
•	Google Meet = live voice & presence
•	Your App = the city
The app is where:
•	value accumulates
•	scores are revealed
•	sponsors compete
•	content lives forever
•	money flows
•	identity is held
Everything else feeds INTO it.
________________________________________
2. What the APP MUST DO (No More, No Less)
Your app has 6 core modules.
If something doesn’t fit one of these, it doesn’t belong.
________________________________________
MODULE 1 — Identity & Profiles (Foundation)
Who has profiles:
•	students
•	parents
•	facilitators
•	sponsors
Student profile shows:
•	avatar (not real photo by default)
•	learning cell(s) joined
•	participation history (positive-only)
•	growth indicators (not grades)
•	produced content (private by default)
  No public comparison between students.
________________________________________
MODULE 2 — Learning Cells & Scores (The Producing Model Made Visible)
Each Learning Cell has a page showing:
•	cell ID / name
•	facilitator
•	cycle duration
•	Growth score
•	Participation health
•	Output reuse
•	Succession impact
These scores:
•	are calculated post-cycle
•	are visible in the app
•	are never discussed in class
This is where the producing model becomes tangible.
________________________________________
MODULE 3 — Content Engine (Repeated, Perfected Classes)
This is huge — and smart.
What lives here:
•	edited lesson recordings
•	best moments from learning cells
•	reusable prompts
•	mini-lessons
•	language patterns
Structure:
•	theme-based (food, travel, opinions…)
•	level-agnostic
•	short, clean, human
This turns:
live learning → reusable digital assets
Which means:
•	less facilitator fatigue
•	more value per lesson
•	scalable quality
________________________________________
MODULE 4 — Sponsor & Public Rankings (Advertising Layer)
Inside the app (and mirrored on the website):
Sponsor dashboard:
•	learning cells supported
•	growth averages
•	succession impact
•	leaderboard position
Public-facing:
•	top sponsors
•	top learning cells
•	system-wide impact
  Sponsors see systems, not students.
This is where competition drives reinvestment.
________________________________________
MODULE 5 — Payments & Circulation (Critical)
This module handles:
•	family payments (if applicable)
•	sponsor payments (learning cells)
•	subscriptions
•	scholarships
Rules:
•	payments go to cells, not individuals
•	transparency on where money flows
•	no hidden fees
•	no pressure pricing
This module enables:
more sponsors → more cells → more access
________________________________________
MODULE 6 — News, Signals & Trust
This is the public narrative layer.
Includes:
•	system updates
•	milestones
•	new sponsors
•	learning cell growth highlights
•	expansion announcements
This builds:
•	credibility
•	momentum
•	community belief
Without marketing noise.

•	never manage tech beyond basics

Cell Coordinator
