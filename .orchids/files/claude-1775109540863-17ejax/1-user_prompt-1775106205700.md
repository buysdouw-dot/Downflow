 THE LEARNING PYRAMID (FOR KIDS)
               🌟
        THINK & WONDER
     (Ask questions • Be curious)

               😊
        SPEAK & EXPRESS
     (Share ideas • Try • Be brave)

               🛠️
        LEARN SKILLS
     (Read • Move • Create)

               🎨
        MAKE & CREATE
     (Build • Draw • Solve)

               🤝
        HELP & SHARE
     (Work together • Teach others)
🧠 HOW TEACHERS EXPLAIN IT TO KIDS
“We start with your ideas.
Then we help you share them.
Then we learn skills.
Then we make things.
And finally, we help others.”

🎒 WHY KIDS LIKE THIS MODEL
There is no wrong place to start
Mistakes are part of learning
Everyone grows at their own speed
Learning feels like playing with purpose
